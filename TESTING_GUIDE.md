# 🧪 Тестирование мультиплеера

## Локальное тестирование

1. **Запусти локальный сервер:**
   ```bash
   python -m http.server 8000
   ```
   Или открой файл `survival_game_multiplayer.html` напрямую в браузере.

2. **Открой две вкладки** с `http://localhost:8000/survival_game_multiplayer.html`

3. **Тестируй host/join flow:**
   - Вкладка 1: Введи никнейм "Host", нажми "HOST CO-OP"
   - Вкладка 1: Скопируй ID комнаты
   - Вкладка 2: Введи никнейм "Guest", вставь ID, нажми "JOIN"
   - Вкладка 1: Нажми "SURVIVE"
   - Обе вкладки должны показать игру с двумя игроками

4. **Проверь консоль (F12):**
   - `[INIT] PeerJS loaded successfully`
   - `[HOST] Room created with ID: xxxxx`
   - `[GUEST] Connecting to host ID: xxxxx`
   - `[HOST] Connection opened successfully!`
   - `[GUEST] Connection opened successfully!`

## Ожидаемый результат

✅ **Хост видит:** 
- Себя (зеленый) и гостя (синий)
- Гостя двигается при нажатии WASD на вкладке гостя
- Логи в консоли о действиях гостя

✅ **Гость видит:**
- Себя (зеленый) и хоста (синий)
- Мир синхронизируется с хоста
- Своё движение отправляется хосту

## Проблемы и решения

**"PeerJS did not load"**
- Проверь интернет соединение
- Обнови страницу
- Попробуй другой браузер

**"peer-unavailable"**
- Обнови обе вкладки
- Создай новую комнату

**Нет второго игрока**
- Убедись что оба игрока подключились
- Проверь консоль на ошибки
- Убедись что хост нажал "SURVIVE"
