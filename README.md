# ☢ WASTELAND - Survival Co-op Game

Браузерная survival co-op игра в духе devast.io с мультиплеером через WebRTC.

## 🎮 Особенности

- **Pure HTML/CSS/JavaScript** - без тяжёлых фреймворков
- **Canvas rendering** для плавной графики  
- **WebRTC мультиплеер** через PeerJS (P2P co-op на 2 игроков)
- **Host-authoritative** архитектура - хост симулирует мир
- **GitHub Pages готовность** - статический хостинг
- **Debug логи** в консоли для отладки соединения

## 🚀 Быстрый старт

### 1. Деплой на GitHub Pages

1. Создай публичный репозиторий на GitHub
2. Загрузи `survival_game_multiplayer.html` в репозиторий
3. Переименуй файл в `index.html` (опционально, для открытия по корню)
4. Зайди в `Settings -> Pages` репозитория
5. Выбери `Deploy from a branch`
6. Выбери ветку (обычно `main`) и папку `/ (root)`
7. Нажми `Save`
8. Открой опубликованный URL вида `https://ВАШЕ_ИМЯ.github.io/РЕПОЗИТОРИЙ/`

### 2. Игра вместе

1. Оба игрока открывают один и тот же URL
2. Вводят никнеймы
3. **Игрок 1** нажимает `HOST CO-OP`
4. **Игрок 1** копирует ID комнаты (кнопка `COPY ID`)
5. **Игрок 2** вставляет ID в поле и нажимает `JOIN`
6. **Игрок 1** нажимает `SURVIVE` для старта игры

## 🐛 Отладка мультиплеера

Откройте консоль разработчика (F12) для просмотра логов:

- `[NETWORK]` - статус соединения
- `[HOST]` - логи хоста
- `[GUEST]` - логи гостя
- `[INIT]` - инициализация PeerJS

### Частые проблемы

**"PeerJS did not load"**
- Проверьте интернет соединение
- Обновите страницу
- Попробуйте другой браузер (Chrome/Firefox)

**"peer-unavailable"**
- Оба игрока обновляют страницу
- Хост создает новую комнату
- Гость использует новый ID

**Соединение обрывается**
- Проверьте стабильность интернета
- Избегайте строгих корпоративных сетей
- Попробуйте мобильный хотспот

## 🏗️ Архитектура мультиплеера

```
Хост (Host)                    Гость (Guest)
├─ Симулирует мир              ├─ Отправляет input/actions
├─ Генерирует карту            ├─ Получает состояние мира
├─ Обрабатывает врагов        └─ Показывает локального игрока
├─ Рассылает состояние мира
└─ Авторитетный источник правды
```

**Flow:**
1. Хост создает PeerJS комнату
2. Гость подключается по ID
3. Гость отправляет movement/actions (20 раз/сек)
4. Хост рассылает полный state (20 раз/сек)
5. Гость рендерит мир от своего лица

## 🔧 Технический стек

- **Frontend**: Vanilla HTML/CSS/JavaScript
- **Рендеринг**: Canvas 2D
- **Мультиплеер**: PeerJS + WebRTC data channels
- **Хостинг**: GitHub Pages (статический)
- **Сигнальный сервер**: Публичный PeerJS сервер (бесплатно)

## 🚨 Ограничения

- **Максимум 2 игрока** (P2P limitation)
- **Требуется современный браузер** с WebRTC
- **Некоторые сети блокируют WebRTC** (корпоративные фильтры)
- **Нет персистентности** - мир сбрасывается при перезагрузке
